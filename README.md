# Laboratorio de IA: registro documental

- Preparacion documental: 2026-11-06.
- Proposito: organizar objetivos, resultados historicos y siguientes decisiones de un laboratorio local de IA.
- Alcance: documentacion; no contiene aplicaciones, modelos, configuracion operativa ni un laboratorio desplegado.
- Visibilidad prevista: privada. Este texto no configura ni acredita permisos de acceso en GitHub.

## Por donde empezar

- [Panel visual de estatus E2E (GitHub Pages)](https://andres-dlt.github.io/laboratorio-ia-docs/).
- [Estado: realizado, propuesto y pendiente](ESTADO.md).
- [Roadmap de un piloto acotado](ROADMAP.md).
- [Evidencia historica y sus limites](EVIDENCIA.md).

## Lineas de trabajo

- Evaluacion de modelos locales mediante tareas de programacion y comprobaciones reales.
- Uso controlado de OpenCode con un espacio de trabajo aislado.
- Investigacion de Flash-Next y de sus requisitos de recursos y contexto.
- Posible integracion posterior de Open WebUI y Computer, tras revisar permisos y comportamiento desatendido.

## Distincion principal

- Existen informes de experimentos y aplicaciones de prueba de octubre de 2026.
- El taller completo Flash Next + Open WebUI + Docker Desktop permanece como plan historico no ejecutado.
- Haber obtenido respuestas o pruebas unitarias correctas no demuestra integracion completa, autonomia del laboratorio ni una calidad universal del modelo.

## Contenido excluido

- Codigo de las aplicaciones evaluadas, scripts, modelos, pesos, binarios y respaldos.
- Configuraciones de equipos o servicios, topologia de red, direcciones, rutas e identificadores personales.
- Credenciales, conversaciones completas y registros de sesiones.
- Automatizaciones que ejecuten tareas, publiquen resultados o contacten servicios por si solas.

## Uso de este registro

- Mantener fecha, condiciones y limitaciones junto a cada resultado.
- Proponer experimentos antes de ejecutarlos y registrar su autorizacion.
- No usar este repositorio como sustituto de los artefactos o de los respaldos locales.
- No presentar ninguna de las integraciones como proyecto oficial o avalado por sus autores.
